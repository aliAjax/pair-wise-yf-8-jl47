# 胶片分镜条核对台

纯前端本地应用（无依赖、无后台）：整理纸质放映胶片片段、拖拽调整放映顺序，
并按**当前顺序**自动累计每段起止时间、登记片边码与声轨偏移、逐段确认同步。
直接打开 `index.html` 即可使用；所有数据保存在浏览器 localStorage，关掉页面再打开可继续核对。

## 对片同步规则

- 每段卡片显示按当前顺序算出的**累计起止时间**，并可在行内登记片边码、时长、声轨偏移（秒，可为负）。
- 满足全部条件才能“确认同步”：片边码已填、颜色正常、无破损、时长有效。
- 确认时定格快照（位置、累计起止、时长、声轨偏移、片边码、确认时间）。
- 以下变更会使确认失效：
  - 调整放映顺序：从最早受影响位置起，后续确认全部失效；
  - 改动某段时长或声轨偏移：该段及其后确认失效；
  - 改动某段片边码：该段确认失效；
  - 某段出现颜色偏移 / 破损：该段确认失效，恢复正常前不能重新确认；
  - 删除片段：该段记为“片段删除”，其后因顺序变化失效。
- 失效的旧确认不删除，转入“同步历史”可随时查看（顶部按钮看全部，卡片上的“该段历史”看单段）。

## 文件划分

- `rules.js`：纯业务规则——累计时间线、确认条件、确认快照、差异/失效判定。
- `store.js`：清单保存——localStorage 读写、增删改、确认/级联失效/历史归档、重开页面兜底对账。
- `app.js`：页面操作——渲染、表单与行内登记、拖拽排序、确认按钮、历史弹层、导出。
- `index.html` / `styles.css`：页面结构与样式。

导出清单为纯文本（含累计起止、片边码、声轨偏移、确认状态），可贴回纸卡旁留档。
