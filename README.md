# 胶片试映同步核对台

纯前端本地应用（无依赖、无后台）：按当前放映顺序计算每段**累计起止时间**，登记
**片边码（Keykode）**和**声轨偏移**，并逐段确认声画同步。直接打开 `index.html`
即可使用，数据保存在浏览器 localStorage，关掉页面再打开继续核对。

## 三个业务文件

| 文件 | 职责 |
| --- | --- |
| `rules.js` | 确认规则（纯逻辑）：累计起止时间、可确认条件、历史确认有效/失效/被取代判定、时间与偏移格式化。不碰 DOM 和存储，可单独在 Node 中测试。 |
| `store.js` | 清单保存：读写 localStorage，提供增删改、移动、换序、追加确认记录等操作；旧版本数据自动补齐新字段。 |
| `app.js` | 页面操作：渲染与事件绑定。规则只问 `rules.js`，数据只读写 `store.js`，自身不保存业务状态。 |

## 确认规则

- **不能确认同步**：片边码未登记；片段仍有颜色偏移或破损；时长无效。
- 确认时快照当时序号、累计起止、时长、片边码、声轨偏移、颜色、破损。
- **顺序、时长或偏移变化**：该段及其后所有段的确认自动失效（累计时间链从片头逐段
  累加，前缀一变后续链值全变）；前面未受影响的段仍然有效。
- **片边码、颜色、破损变化**：只失效本段（内容指纹独立）。
- 片段删除后，其确认记录保留在历史中并标注“片段已从清单删除”。
- 同一片段再次确认时，旧确认**永久留档**、标记为“已被取代”，不会复活；所有历史
  在页面底部“同步确认历史”和每段的“本段确认历史”中可随时查看，状态按当前清单实时复算。

声轨偏移单位为秒：正值表示声音提前，负值表示声音滞后。
